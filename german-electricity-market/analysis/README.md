# Analysis

This folder contains the analytical work used to examine German electricity market and power-system data.

The analysis focuses on the relationship between electricity generation, consumption, the changing generation mix, carbon intensity and redispatch activity.

## Main analytical areas

* Electricity generation by technology
* Electricity consumption and demand patterns
* Renewable electricity generation
* Fossil-fuel generation
* Changes in the German electricity mix over time
* Estimated electricity carbon intensity
* Redispatch and congestion activity
* Trends and relationships between electricity-system variables

## Tools

The analysis is primarily conducted using Microsoft Excel, with data-analysis methods and workflows being developed further using Python and SQL.

## Reproducibility

The analytical datasets are derived from the data in `data/raw/` and `data/processed/`.

Where applicable, calculations, transformations and assumptions are documented within the analysis files or supporting documentation.

This repository is intended as a practical demonstration of data analysis applied to an energy-system question.
