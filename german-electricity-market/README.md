# German Electricity Market & Carbon Intensity Analysis

## Overview

This project analyses German electricity market and carbon-intensity data to explore relationships between electricity generation, market conditions and the decarbonisation of the power system.

The analysis forms part of my developing energy-transition data portfolio and demonstrates practical experience in data preparation, cleaning, analysis and visualisation using Microsoft Excel.

## Objectives

The project aims to:

- analyse patterns in German electricity market data;
- examine changes in electricity carbon intensity;
- investigate relationships between electricity generation and carbon intensity;
- identify temporal patterns and trends relevant to energy-system decarbonisation;
- consider how electricity-system characteristics can inform wider energy-transition analysis.

## Data

The analysis uses publicly available German electricity-system data.

The original data sources and relevant licensing or attribution information will be documented here.

## Methods

The current analysis was conducted primarily using Microsoft Excel, including:

- data cleaning and preparation;
- data organisation and transformation;
- descriptive analysis;
- trend analysis;
- aggregation;
- comparison of variables;
- graphical visualisation.

Further analysis using Python, SQL and R is part of my ongoing data-analytics development.

## Relevance to Energy Transition

Understanding the relationship between electricity generation, market conditions and carbon intensity is important when assessing energy-transition pathways.

The analysis is intended to demonstrate how quantitative energy data can be used to support evidence-based assessment of decarbonisation options.
